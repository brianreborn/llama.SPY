llama.SPY - release status
Version: 0.2.0
Updated: 2026-11-17

Product: llama.SPY (binary: llamaspy)
Focus: FreeBSD-first realtime observability for a running llama.cpp process.
Read-only by design. The target is never written.

Working in this release
- HTTP /metrics (+ optional /slots) observability HUD
- HookScript (JSON) + LLMS1 Game Genie dialect
- Duktape js_body: registerTool / log / readBinding / --list-tools / --call-tool
- Read-only mem backend for bindings (Linux process_vm_readv, then /proc/PID/mem;
  FreeBSD /proc/PID/mem or ptrace PT_IO PIOD_READ_D). Symbol + displacement from
  the module load bias. Build-id mismatch refuses the read.
  scripts/gen-gg-offsets.sh emits real LLMS1 lines from nm/readelf.
- DTrace script packaging + path resolution (live on FreeBSD)
- Linux bpftrace uprobe provider (scripts/llama_decode.bt), HTTP fallback kept
- --serve privilege-separated listener (socketpair, dual child, parent reaper).
  Loopback only. API key required (--api-key or --api-key-file). 0.0.0.0 refused.
- --from-url fetches a README or HookScript and writes a draft. js_body is emptied.
  Remote code is never executed.
- i18n en/ja (compiled-in tables; locales/*.json shipped for reference)

Not in this release
- SHM SnoopV1 ring (socketpair only for --serve)
- Fullscreen TUI
- Live FreeBSD DTrace against a real llama-server (needs a FreeBSD host)
- Live Linux bpftrace against a decoding llama-server (needs root or CAP_BPF and a target)
